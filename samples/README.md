# Samples

Place a **non-confidential** or sanitized RTLA run here so the demo and tests are reproducible.

```
samples/
├─ run_N-1/     # prior run (for regression diff)
├─ run_N/       # current run
└─ output/      # generated Excel/PPTX/observations (gitignored)
```

⚠ Do not commit Microsoft Confidential design data or real RTL with sensitive module names. Sanitize or synthesize sample inputs before pushing to GitHub.
